# 模拟打字机 (Human Typer)

针对**网页输入框禁止粘贴、只能手动敲**的场景：把文字逐字"敲"进输入框，节奏、停顿、手滑改错都模仿真人。

不经过剪贴板、不依赖输入法，中文/全角标点/emoji 都能原样打进去；注入的是系统级真实键盘事件，网页拿到的 `isTrusted` 是 `true`。

## 快速开始

**双击 `模拟打字机.exe`**（免安装，不依赖 Python）。

1. 把文字粘到程序里的大文本框（这里可以正常粘贴，不受网站限制）
2. 点「开始打字」（或 `Ctrl+Enter`）
3. 在倒计时结束前点一下网页里的输入框

打字途中按 `ESC` 停止，`F9` 暂停/继续。中途停了不用重来，没打完的部分会留在输入框里，再点开始就接着打。

## 特性

| 特性 | 说明 |
|---|---|
| 中文直出 | `SendInput` + `KEYEVENTF_UNICODE`，不经过剪贴板与输入法 |
| 真人节奏 | 对数正态间隔 + 标点/换行停顿 + 偶发思考停顿 |
| 手滑回改 | 英文取键盘相邻键打错，中文打了删掉重打，再退格改回 |
| 速度准 | 漂移补偿，实测 103 字预估 24 秒、实际 24.0 秒 |
| 焦点守卫 | 焦点被切走先暂停等它回来，等不回来才停手，不会把字打进别的窗口 |
| 断点续打 | 停止后剩余内容自动保留，直接再点开始 |

## 速度怎么选

按中文算（界面里会实时显示折算的字/分钟）：

| 速度 | 折算 | 像什么样的人 |
|---|---|---|
| 1 字/秒 | 60 字/分 | 不常打字的人 |
| **3 字/秒（默认）** | 180 字/分 | 打字很熟的人，已经偏快 |
| 6 字/秒 | 360 字/分 | 不像真人，除非是英文 |
| 15 字/秒以上 | 900 字/分 | 只适合网站不校验速度、纯灌数据 |

网站有防脚本检测（考试、问卷之类）时别超过 3 字/秒。

## 命令行

源码版：

```bash
python 模拟打字.py -f 文本.txt -d 5 -c 3
python 模拟打字.py -t "要输入的内容" -d 3
```

exe 也能带参数跑（会自动开控制台显示进度）：

```bat
模拟打字机.exe -f 文本.txt -d 5 -c 3
```

其他开关：`--jitter` 节奏抖动、`--typo` 错字率、`--no-typo`、`--no-pause`、`--no-guard`、`--focus-wait`。

## 自己打包

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed --name 模拟打字机 --icon app.ico 模拟打字.py
```

`--windowed` 表示不弹黑色控制台；带参数运行时会自动 `AttachConsole` 挂控制台显示输出。

## 原理

用 Win32 `SendInput` + `KEYEVENTF_UNICODE` 把字符直接送进系统输入队列，绕开剪贴板和输入法；每个字之间按对数正态分布取随机间隔，再叠加标点停顿、思考停顿、手滑改错，并对累计耗时做漂移补偿，所以总时长和设定速度一致。

## 目录

| 文件 | 作用 |
|---|---|
| `模拟打字机.exe` | 打包好的单文件程序（11 MB，自带 Python 运行时） |
| `模拟打字.py` | 主程序源码（图形界面 + 命令行，仅标准库） |
| `启动.bat` | 源码版启动器，自动找本机带 tkinter 的 Python |
| `app.ico` | 程序图标 |
| `使用说明.md` | 详细使用说明 |
| `_test/test_cases.py` | 端到端自测：用 Tk 文本框接住注入的字符逐字比对 |

## 环境

Windows（依赖 Win32 API），Python 3.8+，图形界面需要 tkinter。
